## 发布范围

### 平台核心

- 三层架构：Platform Core、Business Module Packs、Integration Test Packs。
- 契约：17 个 Schema（含 common）、动作注册表 18 个动作、版本兼容检查。
- PRD 知识引擎：模块化来源索引、全量/增量扫描、术语表、待确认清单。
- 场景编译：场景→用例→套件→执行计划、DAG、审批闸门、dry-run。
- 浏览器与页面适配：CDP/Chromium、页面映射、控件动作、数据配方、失败诊断。
- 执行/断言/报告：依赖调度、超时/取消、重试安全、三格式报告、run manifest v2。
- 字段规则引擎：必填、默认值、联动、只读、禁用、保存拦截（保存拦截默认不执行）。

## 已知限制

1. 采购到货/入库/退货未做全操作闭环。
2. 应收/应付仅列表只读。
3. 1,664 个编译场景仍为 draft，不能直接进入正式套件。
4. 页面映射 36 字段仅 8 个 verified。
5. 保存拦截默认不执行，避免产生草稿数据。

## 升级与回滚

- 升级：替换发布包并按 `DEPLOYMENT.md` 执行健康检查。
- 回滚：按 `ROLLBACK.md` 切回上一版本，不删除业务数据。
