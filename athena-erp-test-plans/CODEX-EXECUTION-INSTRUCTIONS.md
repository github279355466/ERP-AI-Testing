# Codex 执行说明：Athena ERP 独立作业测试计划集

你需要依据本目录中的独立测试计划，逐个执行 Athena ERP 测试环境的只读页面探索和测试。

## 强制规则
1. 一次只执行一份测试计划，不跨计划混合操作。
2. 执行前读取该计划全文、README 和页面元素分析报告（若已放入项目）。
3. 先确认当前环境、租户、登录态、当前窗口和目标作业身份。
4. 页面未探索或证据不足时，只做只读探索，不推断字段、规则、按钮或 API。
5. 任何保存、保存并新增、删除、审核、反审核、批量处理、结账动作一律禁止，除非用户另行明确授权并提供专项计划。
6. 关闭未保存页面时，按报告要求选择“直接离开”；若页面内容可能需要保留，先停止并询问。
7. 不记录或输出 URL 中的 token、Cookie、认证文件和账号凭证。
8. 页面导航超时按报告设置 120 秒级别并有限重试；优先等待页面业务信号，不使用固定 sleep。
9. 使用 `label[for="<entity>.<field>"]` 作为已确认表单字段的首选锚点；不要依赖随机 CSS hash。
10. ag-Grid 需考虑虚拟滚动和隐藏行；不要把 DOM 中暂时不存在的虚拟行误判为无数据。
11. 对自定义下拉和 WindowSelect 使用真实用户交互；选择器只打开、检查并取消，不确认选择。
12. 每个测试步骤记录预期、实际、结果、证据路径和异常。
13. 输出本次执行报告，不覆盖原测试计划；发现新事实后另存探索结果，待确认后再更新计划。

## 执行产物
为每份计划创建：
`artifacts/<plan-id>/<run-id>/`
包括：
- execution-report.md
- screenshots/
- dom/
- trace/
- logs/

## 结束条件
完成本计划允许的只读用例后立即停止。明确列出 PASS、FAIL、BLOCKED、NOT RUN；不要继续执行下一份计划，等待用户指示。
