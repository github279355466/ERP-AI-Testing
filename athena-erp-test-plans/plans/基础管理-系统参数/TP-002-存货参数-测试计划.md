# TP-002｜存货参数｜独立测试计划

- **所属模块**：基础管理/系统参数
- **ERP 作业**：存货参数
- **测试环境**：Athena 测试环境（`https://athena-test.digiwincloud.com.cn/`）
- **计划状态**：可按已知页面证据执行只读测试；写入测试待授权
- **依据**：《鼎捷雅典娜（athena-test）页面元素分析报告.md》
- **证据等级**：报告已提供该作业的字段、控件和页面交互细节

## 1. 测试目标

验证「存货参数」作业的页面可访问性、页面结构、查询/列表行为、详情展示、控件交互及其可观察的业务约束。完成页面探索后，再补充经确认的业务规则和写入型测试。

## 2. 测试范围

### 本计划包含
- 从 Athena 门户菜单定位并打开本作业。
- 验证低代码渲染应用是否正确承载本作业。
- 识别列表、详情、编辑态（若存在）及页面标签。
- 识别字段、控件类型、必填标记、只读/禁用状态。
- 识别普通下拉、基础资料选择器、表格、分页及行内操作（实际存在时）。
- 验证只读查询、查看、打开/关闭弹窗等无业务写入行为。
- 记录页面元数据、截图和测试证据。

### 本计划不包含
- 未经授权的新增、保存、修改、删除、审核、反审核、结账或批量操作。
- 未经证实的业务规则、字段联动、数据来源及接口行为。
- 对生产环境或非指定租户执行任何测试。

## 3. 测试依据与待确认项

### 已知页面证据（来自分析报告）

- 页面由门户 Angular SPA 与低代码渲染应用构成；业务页通过独立窗口打开。
- 表单由页面设计元数据驱动，字段定位优先使用 `label[for="<entity>.<field>"]`。
- 列表使用 ag-Grid；行定位可使用 `[row-index]`，列定位可使用 `[col-id]`；需考虑虚拟滚动及隐藏行。
- 基础资料选择器为 WindowSelect，弹窗根节点为 `.rc-dialog-wrap`；普通下拉浮层为 `.ath-select-dropdown`。
- 详情态只读；编辑态可能切换为可编辑控件。测试阶段不得点击保存类按钮。
- 该作业实体：`ops_unit_invnt_param`。

- `switch`：`button.Switch-module_switch__...`，状态由 checked class 表示；只读检查状态，不切换。
- `input`：`input.digi-input`。

## 4. 测试环境与前置条件

- 使用专用测试账号登录 Athena 测试租户；账号凭证不得写入计划、代码或报告。
- 使用分析报告确认的 Chrome CDP 会话（当前探索端口为 `9333`）；端口以本机实际启动配置为准。
- 访问目标域名需要本机代理 `127.0.0.1:10808`；网络等待按实际代理状况配置。
- 导航超时建议 120 秒，并采用有限重试；优先等待页面业务信号，不使用固定长时间 sleep。
- 确认当前租户、组织/运营单元和测试账号权限。
- 执行前检查页面是否已有未保存内容；退出未保存页面时按报告选择“直接离开”，但必须先确认本次没有需要保留的内容。
- 全程保存截图、日志及 Playwright Trace；清理敏感 token、客户资料和个人信息。

## 6. 测试数据与数据保护

- 本计划当前阶段以已有数据只读验证为主，不创建测试数据。
- 不在日志或截图中暴露 token、账号凭证、客户/供应商敏感信息。
- 不对现有记录执行保存、删除、审核或批量操作。
- 后续如批准写入测试，必须先定义唯一测试前缀、测试数据归属、预期影响和经批准的清理方式。
- 禁止通过直接数据库删除方式清理测试数据。

## 7. 执行与通过标准

### 通过标准
- 能准确打开目标作业，页面标题和作业身份有证据。
- 页面结构、控件和字段映射均有截图/DOM/元数据支撑。
- 只读操作不改变业务数据。
- 所有未知项明确标记，不以推测替代验证。
- 测试步骤可重复执行，等待条件基于页面业务信号。

### 失败标准
- 打开错误作业或页面身份无法确认。
- 页面在规定超时内无法稳定加载。
- 页面显示与页面设计元数据存在未解释差异。
- 只读操作意外改变业务数据或触发写入动作。
- 测试证据缺失，无法复现问题。
