# 采购取价服务专项测试报告

- 执行日期：2026-11-10
- 环境：athena-test / digichannel / 运营单元 000W1
- 数据：`QA26` 模拟数据集（保留不清理）
- 方式：真实 Web UI 操作，抓取页面实际发出的取价服务请求
- 覆盖服务：
  - 采购取价服务 `smbcloud.pur_price_strtg.price_svs.get`（采购订单、到货单）
  - 供应商取价服务 `bm.supp_item_price.getprice`（询价单、退货单其他来源）

## 1. 结论摘要

| 场景 | 结果 | 关键值 |
| --- | --- | --- |
| 采购订单 RMB 120 打 | 通过 | 单价 336（第 2 档），金额 40,320 |
| 阶梯边界 99/100/499/500 | 通过（口径待确认） | 99→336、100→336、499→324、500→324 |
| 采购订单 EUR 120 打 | 通过 | 单价 43 EUR，汇率 7.85，本币价税合计 40,506 |
| 计价单位由 KG3 改为 DA | 通过 | 品号采购信息改 DA 后，价格与订单均按 DA 取价 |
| 询价单 120 打 | 部分通过 | 已调用供应商取价服务，最近核价 336；单据保存受自动化日期输入限制 |
| 到货单从订单取单 | 部分通过 | 单价继承 336；库存单位数量未按换算显示（99 而非 1188） |
| 退货单其他来源 | **不通过** | 未调用供应商取价服务，单价保持 0 |

总体判断：采购订单与询价单的取价服务可用，汇率换算正确；退货单“其他来源”取价缺失，到货单单位换算存在异常。

| 入参 | ops_unit=000W1、supp=QA26-S001、item=QA26-M001、unit=DA、ccy=RMB、qty=120、date=2026-11-10、tax_rate=0.13、intax=true、er=1 |
| 回填 | 单价 336、金额 40,320 |

### 3.2 阶梯边界

| 数量（打） | 命中单价 | 对应档位 |
| ---: | ---: | --- |
| 99 | 336 | 第 2 档 99-499 |
| 100 | 336 | 第 2 档 99-499 |
| 499 | 324 | 第 3 档 499 以上 |
| 500 | 324 | 第 3 档 499 以上 |

- 保存单据：`QA20261109-BT1-202611100001`（4 行，已审核）。
- 口径已确认：区间为 `>= 起始数量 AND < 截止数量`（起始含、截止不含），99 归入 99-499、499 归入 499 以上；用例按左闭右开构造。

### 3.3 计价单位更改

| 步骤 | 结果 |
| --- | --- |
| 品号采购信息由 KG3/KG3 改为 DA/DA | 保存成功，计价单位联动为 DA |
| 价格主档新增 DA 价格 | 保存成功（348/336/324），未再报换算关系不存在 |
| 采购订单选品号 | 自动带出 DA/DA，按 DA 取价 336 |
| 订单行直接改计价单位 | 单元格为 disabled，不允许修改 |

- 结论：计价单位变更只能通过品号采购信息维护；维护后订单与价格均按新单位取价。订单行内不允许临时改单位，符合“品号采购单位与计价单位须相同”的约束。

## 7. 缺陷与观察

### DEF-14 退货单其他来源未调用供应商取价服务（S2）

- 页面：采购退货单
- 复现：新建退货单，来源类型=其他，新增明细行选 `QA26-M001`，数量 10，含税，税率 13%。
- 实际：单价保持 0，未发出 `bm.supp_item_price.getprice` 请求。
- 期望：调用供应商取价服务，按 DA/数量 10 取第 1 档 348。
- 证据：`probe/md-rtn-other.json`、`probe/md-rtn-other3.json`。

### OBS-10 新建数量单位在品号单位换算中被替换（未复现，撤回）

- 本轮曾观察到 `1 ST = 12 KG3` 保存后回读为 `1 DA = 12 KG3`；用户复测未复现。
- 结论：撤回，不作为缺陷；后续按标准流程维护基本单位/换算后再复测。
- 证据：`probe/md-itemconv-st2.json`、`probe/md-itemconv-state2.json`。

### OBS-11 单价字段按整数保存（S2/S3）

- RMB 价格录入 28.5 保存为 29；EUR 价格录入 44.5/41.5 保存为 45/42。
- EUR 货币信息“单价取位=4”，但明细仍按整数落库。
- 影响：外币或小数单价无法精确维护，阶梯价只能使用整数。
- 证据：`probe/md-price-m001-da.json`、`probe/md-price-eur.json`。

### OBS-12 到货单库存单位数量未按品号换算（S2，待确认）

- 订单行 99 DA，品号换算 1 DA=12 KG3，到货单取单后库存单位数量显示 99 KG3。
- 影响：若入库沿用该数量，库存将少记 12 倍。
- 证据：`probe/md-arr-from-po.json`。

### OBS-13 阶梯边界口径（已确认，非问题）

- 产品确认：`>= 起始数量 AND < 截止数量`（起始含、截止不含）。
- 实测 99 命中 99-499、499 命中 499 以上，符合口径；后续按左闭右开构造边界。
- 证据：`probe/md-po-boundary.json`、`probe/md-po-boundary-detail3.json`。
