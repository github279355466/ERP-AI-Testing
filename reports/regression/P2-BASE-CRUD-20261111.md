## 3. 复用模式（ar/ap 照此扩）

1. 先探测目标页表单字段 id（`FormItem` 容器 id 即字段路径）。
2. 在 `src/modules/<module>/flows.ts` 写一条 flow：定位行 → 进编辑 → 改字段 → 保存 → 重开回读 → 回滚。
3. 在 `business-modules/<module>/testcases/` 建 YAML，`status: reviewed`。
4. 实跑 `platform-run run --module <module> --case <ID> --allow-write`，通过后纳入 suite。

## 4. 关键实现注意点

- operate 列是**右固定列**，不在 `.ag-center-cols-container` 内，需按 `row-index` 跨容器取。
- 按钮常在视口外，`click()` 会报 outside viewport，改用 `evaluate(node => node.click())`。
- 行匹配用 `ops_unit_no` 单元格精确文本，避免“000W1”与“000W1x”误命中。
