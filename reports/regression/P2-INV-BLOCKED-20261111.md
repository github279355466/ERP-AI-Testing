# P2 库存与成本联动（INV-01~06）可执行性评估（2026-11-11）

- 环境：athena-test / digichannel / 000W1、QN002。
- 方式：只读探测门户菜单、采购入库单与采购退货出库单列表/详情字段；未新增或修改任何单据。
- 结论：**当前环境不可执行**，INV-01~06 全部转 `blocked`，原因分环境缺口与已知缺陷两类。

## 1. 用例状态

| 用例 | 预期 | 当前状态 | 原因 |
| --- | --- | --- | --- |
| INV-01 | 入库审核自动过账，库存增加、过账状态=已过账 | blocked | 入库单无过账状态字段；库存无查询入口；BUG-20261108-01 未修复 |
| INV-02 | 退货出库过账，库存减少且不允许负库存 | blocked | 库存无查询入口；受 BUG-20261108-01 影响审核报“库存数量不足” |
| INV-03 | 入库后成本来源正确 | blocked | 无成本查询/成本明细入口，取价与移动平均不可读 |
| INV-04 | 撤审/取消过账，库存回滚 | blocked | 入库侧无过账状态可对照；库存无查询入口 |
| INV-05 | 盘点调整后账实一致 | blocked | 菜单无盘点作业；库存无查询入口 |
| INV-06 | DA/KG3 换算后库存数量正确 | blocked | 换算结果缺少库存数据源；单位换算主数据可查但无法闭环 |

## 2. 已验证事实

- 门户一级菜单仅有 首页/基础管理/采购管理/销售管理/BOM管理/应付管理/应收管理/运营单元协作/测试，无库存类入口。
- `采购入库单`（`FWGGvzbgedYY`）列表 15 列，无过账状态；状态筛选项为 全部/已审核/审核中/未审核。
- `采购退货出库单`（`GqXCkXLlQWbb`）列表无过账状态，详情字段含 `pur_rtn_stkou_doc.post_stat`。
- `BUG-20261108-01` 状态仍为“待修复”，其对照实验证明入库单未形成可用库存。

## 3. 解除条件

1. 提供库存查询/库存台账页面或只读库存查询接口（运营单元+仓库+品号+批号+储位维度）。
2. 修复 `BUG-20261108-01`，并在入库单列表或详情暴露过账状态。
3. 提供成本查询入口（移动平均单价、成本来源单据）。
4. 盘点作业入口（若盘点由独立产品线承载，需明确不在本期范围）。

满足 1~2 后可先跑 INV-01/02/04；满足 3 后补 INV-03；INV-05/06 依赖 1 与盘点入口。
