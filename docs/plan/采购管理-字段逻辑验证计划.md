## 2. 目标

1. 表单可见字段 100% 登记为规则条目，不允许「没有规则所以不测」。
2. 每条 P1 规则具备正例与反例；反例必须出现明确阻断且单据不落库、状态不前进。
3. 计算类字段（金额、税额、价税合计、可退量、折算金额）必须给出可复算的期望值与容差。
4. 未渲染/隐藏字段标 `skipped` 并注明原因，不得默认为通过。
5. 结果按规则 ID 汇总，失败附截图 + 请求 + 错误文案。

## 4. 规则类型与验证方法

| 类型 | 观测点 | 正例 | 反例 | 层级 |
| --- | --- | --- | --- | --- |
| REQUIRED 必填 | 星号、空值保存 | 填值可保存 | 置空保存被拦截，提示字段名 | L1/L2 |
| DEFAULT_VALUE 默认值 | 开单初始值 | 默认值符合 PRD/参数 | 默认值缺失或错误 | L1 |
| READONLY 只读 | 可聚焦不可输入、禁用态 | 只读字段不可改 | 可编辑即失败 | L1 |
| DISABLED 禁用 | 灰化、不可点击 | 禁用条件成立时不可用 | 条件不成立仍禁用 | L1 |
| LINKAGE 联动 | 变更触发字段 | 供应商变更带出币别/税率 | 未带出或未覆盖 | L2 |
| COMPUTED 计算 | 金额、税额、价税合计 | 按公式复算一致 | 手工改计算字段被拒或重算 | L2 |
| UNIQUE 唯一 | 重复键保存 | 新键可保存 | 重复键被拦截 | L2 |
| STATE_GATED 状态可编辑性 | 状态变化后的字段/按钮集 | 状态与可编辑性符合规则 | 状态不符仍可编辑 | L1/L2 |
| LOOKUP 取值来源 | 开窗行数、回填值 | 来源有数据且回填正确 | 来源为空仍可保存 | L2/L3 |
