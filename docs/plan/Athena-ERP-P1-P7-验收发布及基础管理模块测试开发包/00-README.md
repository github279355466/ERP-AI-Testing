# Athena ERP 自动化测试平台交付包

本包分三道 Gate，必须按顺序执行，每道完成后停止等待人工批准。

-   Gate A：P1--P6 验收。核实真实代码、自动化测试、真实 ERP UI
    执行证据和数据治理。不得因文档或代码存在就判定通过。
-   Gate B：P7 正式发布。版本冻结、RC 构建、部署演练、健康检查、真实 UI
    smoke test、回滚演练、发布审批和发布报告。
-   Gate
    C：基础管理模块完整测试。以当前已开发模块为对象，盘点实际页面、字段、单据、按钮和关联关系，覆盖字段逻辑、CRUD、审核/撤审、生效/失效、取单及其他实际存在的按钮。

环境为 Athena ERP 测试站点
`https://athena-test.digiwincloud.com.cn/`。业务测试、数据准备、查询和写操作必须通过
Playwright 真实 Web UI。禁止用 SQL、数据库直连、OpenAPI 或 MCP 绕过 UI
执行业务测试或准备数据。

Codex
必须先读取整个项目、AGENTS.md、PRD目录、代码、测试、配置、执行记录和报告；先盘点再行动。每项结论必须有证据路径、命令、run
id、截图、trace 或日志。mock、stub、dry-run 不计入真实 UI
通过数。写操作仅限确认过的测试环境、组织和账号；测试数据唯一标识、依赖、清理策略必须完整。不得记录密码、Cookie、Token。
