# 测试覆盖矩阵与指标

## 基础管理模块覆盖矩阵

  ---------------------------------------------------------------------------------------------------
  测试域                  子项                                             最低要求
  ----------------------- ------------------------------------------------ --------------------------
  页面                    菜单、列表、详情、新增/编辑                      全量盘点

  字段                    必填、默认值、格式、长度、精度、唯一性           按适用性覆盖

  联动                    字段依赖、参照选择、组织过滤、状态限制           关键关系全覆盖

  CRUD                    新增、查询、查看、修改、删除                     关键对象100%

  按钮                    审核、撤审、生效、失效、取单及其他实际按钮       全量盘点，关键按钮全验证

  状态                    状态转换、重复/非法操作                          关键转换全覆盖

  取单                    来源筛选、字段带入、数量金额、关联、重复取单     实际存在关系全覆盖

  异常                    缺字段、非法值、超限、无权限、被引用、重复提交   关键异常全覆盖

  数据治理                唯一标识、依赖、清理、审计                       写操作100%可追溯
  ---------------------------------------------------------------------------------------------------

## 覆盖率口径

页面覆盖率=已测试页面/已盘点页面；字段规则覆盖率=已测试字段规则/已识别适用字段规则；按钮覆盖率=已验证按钮/已盘点适用按钮；CRUD覆盖率=已验证动作/适用动作；状态转换覆盖率=已验证转换/已识别适用转换；取单覆盖率=已验证关系/已识别适用关系。
每项保存分子、分母、排除项、待确认项和来源清单。N/A、不可访问、待确认、未测试必须单列，不能静默从分母移除。

## 缺陷分类

PRODUCT_DEFECT、UI_DEFECT、DATA_DEFECT、ENVIRONMENT、AUTOMATION_DEFECT、ASSERTION_DEFECT、SPEC_GAP、PERMISSION、TRIAGE_REQUIRED。每个失败用例必须归类；未知先标待分诊。

## 按钮验收卡

操作ID、模块/页面/对象、按钮名、来源证据、前置状态、字段条件、权限、操作前快照、执行步骤、预期反馈、预期状态、字段/关联变化、负向条件、重复操作结果、证据、实际结果、结论、数据清理策略。

## 质量运营指标

按模块统计页面/字段/按钮/状态/取单覆盖率、用例通过/失败/阻塞/跳过、产品缺陷和严重度、自动化缺陷、环境异常、flaky比例、平均耗时、数据准备成功率、报告生成成功率及版本变更影响。测试通过率和产品质量指标分开展示。
