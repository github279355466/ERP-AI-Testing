- UI：删除/失效入口是否禁用，或点击后是否出现确认与拦截提示。
- 业务：拦截文案是否指明引用对象；被引用数据状态是否保持不变。
- 持久化：刷新列表后状态与引用关系均未变化；引用方数据仍可用。

## 6. 每作业执行模板

1. 建包：确认 `business-modules/purchase/` 下 page-mapping、field-rules、testcases 的落点。
2. 映射：表单可见字段逐个登记 `field_key / 控件类型 / 必填 / 默认值 / 只读 / 联动 / 计算 / 状态条件`。
3. 用例：一条规则一个用例，编号 `FR-<单据>-<类型>-<字段>`；P1 必须正例 + 反例。
4. 执行：真实 UI 操作，禁止 SQL/OpenAPI/MCP 绕过页面；写操作使用 `QA` 前缀数据。
5. 回填：更新规则矩阵、执行报告、缺陷清单；未验证项标 `UNKNOWN` 或 `candidate`。
