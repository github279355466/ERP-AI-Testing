## 2. 总体推进策略

按“先解除阻塞、再扩覆盖、最后复制”的顺序推进，避免在缺陷未修复时重复构造用例。

```text
P0 修复回归（1 周）
  └─ P1 取价体系深化（1.5 周）
        └─ P1 采购单据全链路（1.5 周）
              └─ P2 库存与成本联动（1 周）
                    └─ P2 多模块复制（2 周）
                          └─ P2 平台化与回归（1 周）
```

每个阶段设准入门禁与退出标准，未达标不进入下一阶段。

## 4. P1 取价体系深化（第 2 周 ~ 第 3 周上半）

## 5. P1 采购单据全链路（第 3 周下半 ~ 第 4 周）

### 5.1 链路用例

| 用例 | 链路 | 关键断言 |
| --- | --- | --- |
| CHN-01 | 请购→订单 | 数量、品号、交期带入；超转拦截 |
| CHN-02 | 订单→到货 | 扣已到货量；部分到货可多次取单 |
| CHN-03 | 到货→入库 | 仓库/储位/批号带入；库存单位数量换算 |
| CHN-04 | 入库→退货 | 可退量=已入库−已退；超退拦截 |
| CHN-05 | 退货→退货出库 | 取单、数量、仓库、过账 |
| CHN-06 | 审核/撤审/作废 | 状态机与引用保护；下游存在时禁撤审 |

### 5.2 批号与储位

| 用例 | 场景 | 预期 |
| --- | --- | --- |
| LOT-01 | 批号启用品号收货 | 批号必填，库存按批号归集 |
| LOT-02 | 批号未启用品号 | 批号列不可选 |
| STP-01 | 储位启用仓入库 | 储位必填，可选 A0101/A0102 |
| STP-02 | 储位不启用仓 | 储位列不可用 |

### 5.3 退出标准

- 主链路 6 条全部跑通，至少 1 条正例 + 1 条反例。
- 单据状态、数量、金额、库存单位数量四类断言均通过。
- 断链处有明确缺陷或环境原因。

## 7. P2 多模块复制（第 6 周 ~ 第 7 周）

按“同一套方法 + 独立模块包”复制，不把业务逻辑写进平台核心。

| 模块 | 首批作业 | 复用资产 |
| --- | --- | --- |
| 销售 | 报价、订单、出货、退货 | 取价、单位、汇率、状态机 |
| 应收 | 应收单、收款、核销 | 金额/税额、币种、客户 |
| 应付 | 应付单、付款、三单匹配 | 供应商、采购单据 |
| 库存 | 库存查询、调拨、盘点 | 仓库/储位/批号 |
| 生产 | 工单、领料、报工 | BOM、品号、仓库 |

每个模块交付：`page-mapping + field-rules + testcases + 执行报告 + 缺陷清单`。

## 13. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 缺陷修复周期不确定 | P1 用例反复阻塞 | P0 先回归；未修复项用替身数据绕过并标注 |
| 环境汇率/参数被改动 | 金额断言不稳定 | 固定业务汇率日期与值，执行前快照 |
| 单价精度限制（OBS-11） | 外币小数价无法验证 | 先用整数价覆盖逻辑，精度单独立项 |
| 到货库存换算（OBS-12） | 库存链路数量错误 | 优先回归，未修复前不扩展库存用例 |
| 页面横向滚动/虚拟列 | 字段采集遗漏 | 统一使用滚动采集脚本，禁止只读首屏 |
