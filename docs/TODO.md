## T-10 录单多笔明细与带回默认值复测

- 状态：进行中（2026-11-12：已支持多笔明细并新增用例 `CRUD-PURCHASE-ORDER-MULTILINE`；执行受 `DEF-20261112-01` 阻断）

- 规范：录单（取单带回或手工新增品号）必须至少 3 笔明细，逐笔校验默认值与派生字段
- 背景：已发现部分作业单笔正确、多笔结果错误

- 验收标准：≥3 笔明细的录单用例全部通过，失败留 UI + 请求证据
