## 0. 校验边界

本规范**只约束字段与列的排列、顺序、分组和显示格式**。

| 不校验             | 原因                            |
| --------------- | ----------------------------- |
| 主题色（Banner 配色等） | 由平台统一组件与主题配置提供                |
| 字体、字号、行高        | 由平台统一组件提供                     |
| 间距、圆角、阴影        | 由平台统一组件提供                     |
| 控件尺寸、列宽         | 由平台统一组件提供，仅约束「状态列在操作列之前」等位置关系 |

**状态色纳入校验**：列表页状态列颜色、详情页状态图章颜色必须匹配颜色规则（见 L1-16、L3-07）。

标注口径（遵循 `AGENTS.md` §1）：

- `verified`：规范图中有明确文字或样例页面可直接对照。
- `candidate`：从图中版面推断、图中未逐字写明，或为口头补充、图上未完整表达的规则。
- `UNKNOWN`：规范图未覆盖。

| 规则    | 内容                                            | 状态        |

| L1-13 | 业务字段按「主体 → 往来 → 部门/人员 → 金额」分组排列               | candidate |

### 1.5 行内操作按钮

按钮全集顺序：查看、编辑、提交、审核、驳回、撤审、作废、删除。

| 单据状态 | 可见按钮              | 状态       |
| ---- | ----------------- | -------- |
| 已审核  | 查看、撤审             | verified |
| 审核中  | 查看、审核、驳回          | verified |
| 未审核  | 查看、编辑、提交、审核、作废、删除 | verified |
| 作废   | 查看                | verified |

- 规则 L1-14：按钮顺序固定为上述全集顺序，超出宽度的按钮自动收进「…」，点击「…」展开全部收起按钮，展开后顺序与可见性规则不变。
- 规则 L1-15：按钮可见性由审核状态驱动，不得所有状态展示同一套按钮。
- 规则 L1-16：状态列颜色规则为「已审核-绿色、审核中-蓝色、未审核-黄色、作废-灰色」，需逐状态校验。

## 2. 单据类详情页（S2 / 参照 S6）

### 2.1 头部 Banner 结构

| 规则    | 内容                                              | 状态       |
| ----- | ----------------------------------------------- | -------- |
| D2-01 | 页面顶部为业务 Banner，左侧为单据图标与单据名称                     | verified |
| D2-02 | Banner 业务信息配置「单号」并开启支持复制                        | verified |
| D2-03 | 合计信息通过「数值统计」配置，最多 3 个（价税合计、无税金额、税额），横向排列，没有可不配置 | verified |
| D2-04 | 右上角显示状态图章，需与当前单据状态对应，颜色同列表页状态列（见 L1-16）         | verified |

> Banner 主题色（浅紫）属平台主题，不在校验范围；状态图章颜色需校验。

> D2-10 的验证方式：查看态开窗输入框为只读，因此统一在「新增」表单中抽样验证——聚焦开窗字段、输入名称片段，观察下拉结果是否 ≥1 条；同时记录按编号片段是否可检索，作为区分「不支持模糊查询」与「仅支持编号检索」的证据。

### 2.2 单头字段排列

| 规则    | 内容                                        | 状态                        |
| ----- | ----------------------------------------- | ------------------------- |
| D2-05 | 基本信息与管理信息做成**多页签**样式                      | verified                  |
| D2-06 | 重要字段靠左，整体横向排布；字段按行从左到右排列                  | verified                  |
| D2-07 | 必填字段以红色 `*` 标识在标签左侧                       | verified                  |
| D2-08 | 开窗字段显示「名称（编号）」，名称在外、编号在内                  | verified                  |
| D2-09 | 开窗控件类型为「搜索 + 开窗」，右侧提供开窗入口                 | verified                  |

| D2-11 | 开窗标题需配置；未配置时默认显示「弹窗标题」                    | verified（2026-11-12 用户确认） |

## 3. 基础资料列表页（S3）

| 规则    | 内容                                                                                              | 状态       |
| ----- | ----------------------------------------------------------------------------------------------- | -------- |
| L3-01 | 标签组为生失效状态，按资料类型分两种：① 一般基础资料为「全部、生效、失效」；② 特殊作业类（品号类、供应商类、客户类等）为「全部、生效、失效、未生效」。需检查生失效状态及末尾「+」新增入口 | verified |
| L3-02 | 「更多」为自动收起入口：标签超过 3 个时自动收起并显示「更多」，点击弹出全部收起标签，面板内顺序与标签组顺序一致                                       | verified |
| L3-03 | 操作列按钮取决于标签组是否包含「未生效」：有「未生效」按三态规则，无则按两态规则                                                        | verified |
| L3-04 | 批量按钮顺序（高频在左）：三态为「生效、取消生效、失效、重新生效、删除」，两态为「生效、失效、删除」                                              | verified |
| L3-05 | 编号与名称分两列，编号列后紧跟名称列                                                                              | verified |
| L3-06 | 末两列为「状态」「操作」                                                                                    | verified |
| L3-07 | 状态列颜色规则：生效-绿色、未生效-黄色、失效-灰色                                                                      | verified |

情况 1：有「未生效」状态（品号类、供应商类、客户类等特殊作业）

| 资料状态 | 可见按钮             | 状态       |
| ---- | ---------------- | -------- |
| 生效   | 查看、编辑、取消生效、失效、删除 | verified |
| 未生效  | 查看、编辑、生效、删除      | verified |
| 失效   | 查看、重新生效、删除       | verified |

情况 2：无「未生效」状态（一般基础资料）

| 资料状态 | 可见按钮        | 状态       |
| ---- | ----------- | -------- |
| 生效   | 查看、编辑、失效、删除 | verified |
| 失效   | 查看、生效、删除    | verified |
