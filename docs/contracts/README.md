# 契约文档索引

运行时 Schema 位于 `platform/contracts/schemas/`，本目录提供人类可读说明。

| 文档 | 对应 Schema |
| --- | --- |
| `platform/contracts/README.md` | 契约总览 |
| `docs/architecture/TO-BE.md` | 三层架构 |
| `docs/architecture/BOUNDARIES.md` | 平台/模块/集成边界 |
| `docs/runbooks/validate-contracts.md` | 契约校验操作 |
| `docs/runbooks/module-onboarding.md` | 新增模块包流程 |
| `docs/contracts/module-manifest.md` | `module-manifest` |
| `docs/contracts/scenario.md` | `scenario` |
| `docs/contracts/test-case.md` | `test-case` |
| `docs/contracts/page-mapping.md` | `page-mapping` |
| `docs/contracts/data-recipe.md` | `data-recipe` |
| `docs/contracts/execution-report.md` | `execution-report` |
| `docs/contracts/run-manifest-v2.md` | `run-manifest-v2` |
| `docs/contracts/integration-pack.md` | `integration-pack` |
| `docs/contracts/action-registry.md` | `action-registry` |
| `docs/contracts/field-rule-set.md` | `field-rule` |

核心契约：

- `module-manifest`：模块包 `module.yaml`
- `scenario`：业务场景
- `test-case`：测试用例
- `page-mapping`：页面/字段/控件映射
- `data-recipe`：UI 数据配方
- `execution-report`：执行报告
- `run-manifest-v2`：运行清单 v2 与 v1 适配
- `integration-pack`：跨模块集成包
- `action-registry`：受控动作注册表
- `field-rule`：字段规则集与页面探针
- `test-suite` / `execution-plan`：套件与执行计划
- `run-config` / `environment-profile` / `user-profile`：运行时配置
