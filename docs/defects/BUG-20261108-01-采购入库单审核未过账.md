## 二、问题描述

采购入库单审核后状态为“已审核”，但库存未形成可用量。随后采购退货单审核触发服务端自动生成并过账采购退货出库单，过账校验返回“库存数量不足”，退货单停留在“审核中”。

## 三、前置条件

- 运营单元 QN002，供应商 SUPP-1001，品号 01-2-00011（非批号管理），仓库 00CP（成品仓，储位管理=不启用）。
- 存货业务单别 IM0402 已配置为自动编码且生效。
- 采购单别参数 QN002+PO1102 的归属单别为 IM0402。

## 四、复现步骤

1. 新建采购订单 `PO0501-2026110800003`（QN002 / SUPP-1001 / 01-2-00011 / 2 KG），提交并审核。
2. 由该订单创建采购到货单 `PO0602-2611080002`，提交并审核。
3. 由到货单创建采购入库单 `IM0301-2026110800003`（仓库 00CP），提交并审核，状态显示“已审核”。
4. 追加一条 100 KG 链路：订单 `PO0501-2026110800004` → 到货 `PO0602-2611080003` → 入库 `IM0301-2026110800004`（仓库 00CP），全部审核。
5. 新建采购退货单 `P2RTN-20261108-04`（QN002 / SUPP-1001 / PO1102 / 来源 `PO0501-2026110800003` / 01-2-00011 / 1 KG / 仓库 00CP），保存并提交。
6. 在采购退货单列表对该单执行“审核”。

## 五、实际结果

- 审核返回 `code=B.BMC-POSC-AT.001.4593`，`message` 为：
  `调用API：bm.pur_rtn_stkou_doc.post出错，错误信息：库存数量不足！`
- 服务端调用链：`PurRtnDocApproveInterceptor.autoPost` → `BmCommonUtils.invokeSyncApi` → `bm.pur_rtn_stkou_doc.post`。
- 采购退货单停留在“审核中”，未生成采购退货出库单。

## 六、期望结果

- 入库单审核即过账，QN002 / 00CP / 01-2-00011 的可用库存应为 102 KG。
- 退货单审核自动生成 IM0402 出库单并过账成功，退货单状态变为“已审核”。

## 七、对照实验（关键证据）

- 临时将 QN002/00CP 的“允许负库存”置为启用（`bm.whse.update`，`allow_neg_invnt=true`）。
- 对同一张退货单 `P2RTN-20261108-04` 重新审核：返回 `code=0`，无错误信息，单据状态变为 **已审核**。
- 自动生成出库单 **IM0402-202611080001**：QN002 / SUPP-1001 / 2026-11-08；明细 01-2-00011 / 1 KG / 仓库 00CP / 储位空 / 批号空 / 来源单 P2RTN-20261108-04；状态 **已审核**、过账状态 **已过账**。
- 结论：同一请求在允许负库存后立即成功，说明实际可用库存小于 1 KG（推断为 0）；两张“已审核”入库单未形成可用库存。
- 验证后已取消“允许负库存”并保存，接口 `bm.whse.get` 返回 `allow_neg_invnt=false`，配置已恢复原状。

## 八、已排除项

1. 数量不足：退货仅 1 KG，入库累计 102 KG。
2. 批号维度：品号 01-2-00011 为“非批号管理”。
3. 储位维度：仓库 00CP 储位管理=不启用。
4. 仓库归属：00CP、C001 均属 QN002 且状态生效。
5. 出库单取错仓库：实际出库单使用退货明细仓库 00CP，而非品号主要仓库 C001。
6. 单别编码：IM0402 已是“年月日+流水码”，自动编码生效，单号必填错误已消失。

## 九、影响范围

- QN002 所有采购退货单审核必然失败，采购退货出库单无法自动生成。
- 手工“取单-开窗”链路另存在缺陷（见关联问题），无法作为兜底方案。
- 库存账实不符：入库单显示已审核，但库存未增加，影响后续出库、盘点与成本。

## 十、修复建议

1. 修复采购入库单审核的库存过账逻辑，确保“审核即过账”，按 运营单元+仓库+品号+批号+储位 写入库存台账。
2. 在入库单列表/详情增加“过账状态”并可见，便于业务与测试核验。
3. 若产品设计已拆分“审核”和“过账”，需提供明确的过账入口与未过账提示。
4. 出库单过账失败时返回可诊断信息（校验维度与可用量），避免仅返回“库存数量不足”。

## 十一、回归验证要点

- 关闭“允许负库存”后重跑步骤 6，应审核成功并生成 IM0402 出库单。
- 出库单状态为“已审核”、过账状态为“已过账”，来源单、品号、数量、仓库与退货单一致。
- 入库单审核后，可用库存应等于入库累计量，且出库后正确扣减。
